# 工單內容範本

此檔供填入 Linear 工單；進度與工作範圍以 Linear 為唯一共享紀錄，repo 不維護平行狀態表。

| 欄位 | 內容 |
| --- | --- |
| 工單 ID／連結與本輪授權引用 | 待設定／待確認 |
| 目標與動機 | 待確認 |
| 負責人／協調聯絡方式 | 待設定 |
| In scope／out of scope | 待確認 |
| 依賴／輸入輸出介面 | 待確認 |
| AC 編號／有限驗證案例與預期結果 | 待確認 |
| Branch／相關 PR | 待設定 |

開單前查核：記錄查核時間、搜尋的 Linear 工單與 PR、相關負責人、重複／重疊／依賴判斷及處理結果。重複沿用既有工單；重疊先協調工作邊界；無法協調才找目前工作負責人。共享紀錄看不到他人未提交工作，不宣稱完全排他。

執行期間可隨時在工作樹記錄新發現或範圍變化，但應同步集中至 Linear。範圍內調整自主處理；涉及產品方向、超出本輪授權或他人工作所有權的調整，先找對應的人，不自行接管。

交付時填入實際驗證命令、exit code／結果、PR、review 紀錄與 reviewed Head、合併版本、交付取得方式及可重現驗收步驟；工程交付與人員產品驗收結果分開。
