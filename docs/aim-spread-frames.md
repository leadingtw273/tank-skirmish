# LEA-171：四層擴散準星框（互動MVP）

在訓練場按F6試玩。框預設開啟；保留原本紅白瞄準線與預設關閉的淡藍圓錐，以便比較。

四層位置是砲口到白線終點的25%、50%、75%、100%；遇到建築或地面時整串以該碰撞終點縮短。每層平面垂直於真實炮管，半徑為該層距離乘tan(當前擴散半角)，不是貼螢幕的等大圖示。靠近砲口3m內及零擴散時隱藏退化框。

依使用者草圖，近至遠是閉合六角框與中心點、分段六角框與中心點、上下箭頭/左右括框與小十字、較大十字的箭頭括框。只讀LEA-170擴散值，不更動射擊取樣、速度、傷害或碰撞。

## 手調

`main.tscn → PlayerRuntime → AimPresentation → 四層擴散準星`

- `Show Spread Frames`：四層框開關，獨立於藍色靶控制的圓錐。
- `Spread Frames Color`：顏色與透明度，初版深色、A=0.9，避免混入訓練場白色格線。
- `Spread Frames Line Width`：世界線寬（公尺），初版0.08，四層不因半徑放大而變粗。

初版不改既有滑鼠游標、不移除紅白線、不加入額外命中預測。外觀由leadi試玩後同單微調，尚未人工驗收。
