# LEA-171：動態切片擴散準星框（互動MVP）

在訓練場按F6試玩。框預設開啟；保留原本紅白瞄準線與預設關閉的淡藍圓錐，以便比較。

切片沿砲口到白線終點平均排列，預設不退縮。中途切片平面垂直於真實炮管；最末片依砲口射線第一個命中物決定朝向與樣式。半徑為該片軸向距離乘tan(當前擴散半角)，不是貼螢幕的等大圖示。砲口3m內及零擴散時隱藏退化框。

## 最末準心依命中物切換

- 第一個命中物是地面（地面碰撞圖層128）：最末準心平貼地面、上方朝坦克，固定第三大款只縮放；不重複顯示該片定位線與三角形。
- 第一個命中物是坦克、建築、靶子等立體物件：最末片恢復垂直瞄準軸，依1／2／4m半徑門檻自動換款，恢復向地面的定位線與三角形。
- 射線沒命中：維持圓錐切片，不在遠方地面另外放貼地準心；下方沒有地面的定位線仍不顯示。

模式依砲口射線的最先命中物判定，不依滑鼠下方物件，也不因物件後方或下方有地面而改判。定位三角形的1m高度門檻保留。這只改UI，不改碰撞、射擊或地面範圍框。

## 切片間距

背景：固定四片在遠處太疏、近處太密。改為世界距離驅動片數，只有顯示元件受影響，射擊與鏡頭不變。

- 每段間距 = 總長度 / 片數；初始四片，首次更新即依距離調整。
- 超過最大25m：增加片數，再平均排列。
- 小於最小15m：減少片數，再平均排列；至少一片，且減片後不得超過最大25m。
- 等於門檻或介於其間：保留片數。距離突然大變時可一次調整多片。
- 100m四片 → 101m五片 → 75m仍五片 → 74m四片。
- 距離不足15m時保留一片；3m內隱藏規則仍優先。

不採用螢幕像素間距，避免鏡頭縮放自行改變片數；也不每幀重算唯一片數，保留穩定區間。若整數片數無法同時滿足上下限，優先不超過最大間距：例如26m保留兩片（13m），不反覆增減；縮到25m才減為一片。

間距15／25m計算基準不變，退縮歸零。地面模式時，末片中心位於命中地面的位置，高度微偏移0.03m避免閃爍；圖樣平貼地面且上方朝向坦克，不另畫該片定位線／三角形。立體物件或未命中時，末片恢復垂直瞄準軸，依半徑換款，並在下方有地面時顯示定位。真正瞄準落點、地面梯形與彈道不變，這不是新增命中預測。

每一層會依當前世界半徑選擇草圖樣式，不再固定「第幾層用第幾款」；同時可以出現多個相同樣式。只讀LEA-170擴散值，不更動射擊取樣、速度、傷害或碰撞。

| 當前半徑（不是直徑或螢幕像素） | 準星樣式 |
|---|---|
| ≤1m | 閉合六角框＋中心點 |
| >1m、≤2m | 分段六角框＋中心點 |
| >2m、≤4m | 上下箭頭／左右括框＋小十字 |
| >4m | 上下箭頭／左右括框＋大十字 |

變大或變小跨越門檻都會換款；各款仍貼合實際擴散半徑，不把彈道範圍量化成四種固定大小。只有樣式改變時才重建該層圖形，普通張合不每幀重新建立。

## 地面擴散範圍框

命中地面時的末端準心：固定原設計第三大款（第二款／索引1：分段六角框＋中心點），只依擴散半徑縮放。中途切片及命中立體物件／未命中時的末片，仍使用1／2／4m半徑門檻換款；此變更不影響下述地面梯形框。

預設為連續實線、Alpha 0.4（40%不透明）。留白長度設0代表實線；提高留白仍可切回虛線。

在有限瞄準圓錐碰到地面時，顯示深色梯形框，與淡藍圓錐開關獨立。沿用實際砲口、白線終點及擴散角；沒有交界就隱藏。只提供近似視覺範圍，不代表精確曲線、命中率或新增落點預測。

從地面專用碰撞圖層取得局部平面；以有限圓錐截面取樣求交界，再用梯形近似包住樣本。第一版以現有平坦地面為主，不處理地圖邊緣裁切、起伏網格或完全垂直瞄準的圓形交界。

`AimPresentation → 地面擴散範圍框`：

- `Show Ground Spread Outline`：預設開啟；不需要打開淡藍圓錐。
- `Ground Spread Outline Color`：預設深色，不透明度0.4。
- `Ground Spread Outline Width`：線寬，預設0.12公尺。
- `Ground Spread Dash Length`：每段實線長度，預設0.8公尺。
- `Ground Spread Gap Length`：每段空白長度，預設0（實線）。

驗收方式：在訓練場朝地面瞄準，拉遠或增加擴散觀察梯形改變；抬高砲管使圓錐離地時應消失。射擊規則、切片與相機不變。

## 手調

### 每片地面定位

每個可見切片中心向世界正下方畫一條定位線，連至地面；落點顯示空心三角形，三角形尖端朝瞄準方向。只有地面模式的最末片不另外畫定位線或三角形。中心在地下、下方無地面或切片隱藏時，不顯示該組定位；切片增減同步增減。與淡藍圓錐及地面梯形開關互不相依，但關閉切片會連同其定位一起隱藏。

`AimPresentation → 切片地面定位`：

- `Show Slice Ground Markers`：定位線及三角形開關，預設開啟。
- `Slice Ground Marker Color`：預設深色、Alpha 0.75。
- `Slice Ground Marker Width`：線寬，預設0.08公尺，不隨切片半徑縮放。
- `Slice Ground Triangle Size`：三角形中心至尖端，預設0.6公尺。
- `Slice Ground Triangle Min Height`：預設1公尺；切片中心離地小於此值時只隱藏三角形，定位線與切片保留。等於或超過門檻時重新顯示。

定位只查地面專用碰撞圖層，不將草或建築當地面；不更動射擊碰撞或傷害。第一版以目前平坦地面為主。

### 切片本身

`main.tscn → PlayerRuntime → AimPresentation → 擴散準星切片`

- `Show Spread Frames`：切片框開關，獨立於藍色靶控制的圓錐。
- `Spread Frames Color`：顏色與透明度，初版深色、A=0.9，避免混入訓練場白色格線。
- `Spread Frames Line Width`：世界線寬（公尺），初版0.08，不因半徑放大而變粗。
- 最小／最大切片間距：預設15／25公尺。
- `Spread Frames Inset Meters`：預設0，保留均分位置；手動提高時，整串切片往砲口退縮，半徑跟著新距離更新，不移動真正瞄準落點。
- 三個樣式切換半徑：預設1、2、4公尺，可在同一分類調整。

不改既有滑鼠游標、不移除紅白線、不加入額外命中預測。leadi 已於2026-09-08確認目前視覺定案；後續工程整理必須保留上述外觀、參數與操作。

## 程式責任與測試

- `src/player/aim_presentation.gd`：取得砲口射線、擴散角與地面取樣，協調各顯示元件。每次更新只取得一次擴散角，貼地末片與地面框共用一次地面取樣；中途切片仍各自查詢下方地面。
- `src/player/aim_spread_frames.gd`：依距離增減切片，計算半徑、選樣式並繪製。貼地末片由協調端調整方向。
- `src/player/aim_ground_outline.gd`：依已取得的局部地面平面，計算與繪製梯形框。
- `src/player/aim_slice_ground_markers.gd`：依已取得的定位資料繪製垂線與三角形。

貼地末片以明確的節點參數傳給定位流程，排除該片，不再透過節點 metadata 傳遞隱含狀態。現有 Inspector 參數名稱與預設值保留；本次不新增資源配置框架、節點池或跨影格快取。

`tests/smoke.gd` 保留整體測試入口；`tests/aim_spread_presentation_smoke.gd` 集中切片／定位／地面框驗證；`tests/aim_target_mode_smoke.gd` 使用真實物理 fixture 驗證地面、立體物件與未命中的模式切換。純幾何與合成位置使用獨立顯示實例，不覆寫遊戲中的顯示節點。測試中的10／25m是明確指定的自訂間距案例，遊戲預設仍是15／25m。
