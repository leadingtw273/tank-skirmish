# 敵方坦克移動（LEA-175）

本功能在既有訓練場實作，採單人、四車型互動驗收。不改玩家坦克物理、武器射程與瞄準機械限制。需求與初值已核可；工程測試與人類試玩狀態以工單紀錄為準。

## 行為

- 優先序：實際可見敵人 > 有效受擊查看 > 最後目擊位置。
- 看得見時追近：各車型獨立設定 `ai_stop_distance = 40`、`ai_resume_distance = 55`（公尺）。既有追近要到停止距離；已停車要超過恢復距離才重新前進。首次看見位於帶內則停車朝敵。
- 距離一律是雙方穩定車身中心的水平直線距離，不是砲口距離或繞障路徑長度。
- 停車後車頭朝敵，完成容差5度；太近不後退。此容差不放寬射擊條件。
- 行進時路徑轉向優先；砲塔／砲管仍可瞄準。固定砲塔不得為瞄準而偏離路線，真正符合原可見／機械／射線首撞與冷卻條件才射擊。
- 失視時前往最後目擊的穩定車身中心世界位置，不追讀隱藏玩家座標，且不開火。
- 搜索抵達原始位置3公尺內就待命，不巡邏。重新看見立即替換舊搜索；有效受擊停止並取消舊搜索，查看後未見目標就待命、不恢復舊路線。
- 基本繞障：部分路線走到安全末端停車；完全無路原地停車；途中卡住停止前進。路線末端不冒充抵達目擊點。
- 預期前進時3秒內進展不足0.5公尺判卡住，排除正常原地轉向、減速與待命。受阻後同一不動目標不每幀重試；可見目標移動3公尺或新目標／重新可見才開始新嘗試。
- 可見且距離合適但射線受阻時，停車朝敵，不自行尋找射擊位置。

## 控制責任

`TankVision` 保留可見性與穩定中心查詢；`TankCombatAI` 保存記憶與交戰啟停狀態，並且是唯一車身指令出口；`TankNavigation` 只提供路徑、行進／轉向需求與到達／受阻結果；`TankController` 保留真實物理、碰撞與砲塔機械約束。

AI 正常物理更新依序感知、決策、取得導航需求、更新砲塔／砲管瞄準、統一提交車身指令、最後檢查射擊資格。瞄準輔助不再自行把前進歸零。生命週期停止也經過同一出口；換車、死亡、停用及目標替換都清理舊路線。

## 導航界線

使用 Godot 原生導航，地圖是訓練場固定地面與靜態建築；導航不直接寫 `velocity`，也不建立另一套駕駛物理。動態群體避讓與破壞後重烘焙不在本版。
四車共用覆蓋真實旋轉碰撞包絡的保守半徑，額外每側1公尺餘裕；小車不保證能走專屬窄道。砲管有真碰撞，不為縮小導航半徑而忽略。
先等導航地圖同步，再區分路線有效、部分末端及完全無路。原始目擊位置與投影後路線終點分開保存。

## 有限驗收清單

| 案例 | 可觀察結果 |
|---|---|
| A1 追近 | 四車80公尺追近到40±1公尺並停車朝敵，轉正<=5度。 |
| A2 雙門檻 | 首見47／55公尺不前進，56公尺追近；既有追近在47公尺不能提前待命。 |
| A3 過近 | 不倒退，持續朝敵。 |
| A4 射擊 | 固定／旋轉砲塔行進和轉正時可依原條件開火；隱藏或射線受阻零射擊。 |
| A5 隱藏搜索 | 隱藏玩家改位置不更新世界搜索點。 |
| A6 搜索完成 | 可走淨空區原目擊點3公尺內抵達後待命至少5秒。 |
| A7 優先中斷 | 受擊取消舊搜索；重新可見立即重定目標，可見優先。 |
| A8 建築繞障 | 四車真物理通過訓練場原建築繞行路線，不穿牆。 |
| A9 不可達 | 過窄通道不直穿；部分末端與完全無路分開，末端不能冒充抵達。途中卡住停止，不反覆重啟；正常原地轉向不算卡住。 |
| A10 控制仲裁 | 行進路徑優先，停車朝敵；導航不寫車身控制，AI統一提交。 |
| A11 生命週期 | 停用、死亡、換受控車、清除／替換目標均清舊命令與搜索。 |
| A12 回歸 | 索敵、碰撞、射擊與玩家操控保持；僅更換被明確取代的靜止斷言。 |

## 實作與驗證順序

1. `scripts/bake_training_ground_navigation.gd` 從四車正式碰撞資產量測旋轉包絡，烘焙原生靜態導航；不搬動建築或縮小其碰撞。
2. `TankNavigation` 提供純需求，`TankCombatAI` 整合追近、轉正與搜索；車型場景只新增距離參數，不變更物理或射擊常數。
3. `enemy_navigation_smoke.gd` 驗地圖與四車真繞障／部分末端；`enemy_movement_smoke.gd` 驗追近、搜索、優先與生命週期；舊 smoke 保留記憶和射擊回歸。
4. `bash scripts/ci.sh` 序列跑完整回歸，獨立複審後交 Windows 試玩；人類驗收前不合併或結案。

## 不包含

主動後退、巡邏、戰術選位、掩體策略、部位傷害與裝甲、動態破壞導航、多車編隊、多人網路、通用AI框架。車頭朝敵只為未來正面裝甲提供行為基礎。

## 親測入口

在本次工作樹開啟 `src/world/training_ground/training_ground_playtest.tscn`，F6執行；沿用粉色敵方換車靶切換四車。拉遠觀察追近、靠近觀察停車朝敵、利用建築遮擋觀察最後目擊搜索；不要用仍指向舊工作樹的編輯器驗收。
