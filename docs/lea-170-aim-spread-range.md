# LEA-170：瞄準擴散與準確度靶場

## 人工驗收紀錄

2026-09-07，leadi 確認「可以這單子驗收調整完成」。本文件所列互動調整已通過人工驗收，包括擴散手感、靶場配置、圓錐開關與碰地深藍截面；所有場景的圓錐預設關閉。此紀錄代表產品驗收通過，不代表程式審查、公開 PR 或合併已完成。

## 開啟與試射

在 Godot 開啟 `src/world/training_ground/training_ground_playtest.tscn`，按 F6 遊玩目前場景。原本四台靶車保留；新增射擊走道位於它們旁邊，主靶為 10×10 公尺、每格 1 公尺。

沿地面 25／50／75／100 公尺線停車，固定瞄準十字靶心連射，再比較移動、原地轉向、左右轉砲塔與停穩後的落點。距離自靶板正面量至地面線，不是即時砲口測距。鏡頭角度、滾輪上限和滑鼠前視距離不變；遠距時可拉遠並把游標移向靶子。

命中點會一直保留到這次遊戲結束，或射中距主靶 60 公尺處、走道左側的 **4×4 公尺「清除彈著」靶**。兩個開關靶避開地面的 50 公尺標示。清除靶不會毀損，可反覆使用。這不是新血量或計分玩法。

綠色清除靶旁另有 **4×4 公尺淡藍色「圓錐開關」靶**：兩靶位於射擊走道左側，同高度左右並排，邊緣空隙為 4m（中心相距 8m），文字放大為原本 5 倍並置於靶板下方。每射中淡藍靶一次，切換暫時擴散圓錐的顯示／隱藏。淡藍靶不清除彈著、不改實際擴散；綠靶仍只負責清除彈著。此開關只影響本次遊戲，重開時沿用 Inspector 的 `Show Spread Cone` 初始值。

## 坦克參數在哪裡

淡藍色圓錐與可見地面相交時，截面會顯示較深的藍色。這是依畫面深度繪製的暫時提示，不會改變射擊或碰撞；可在 AimPresentation 的 `Spread Cone Ground Contact Color` 調整顏色與透明度。

開啟 `src/actors/tank/variants/tank1/tank1.tscn`（或 tank2／tank3／tank4），選最上層坦克節點，在 Inspector 找 **瞄準擴散**。四型保存相同初值，可分別微調；場景內的實例覆寫值優先於共用控制器。

| 參數 | 初值 | 用途 |
|---|---:|---|
| Aim Spread Base Degrees | 1° | 完全穩定時的最小半角（leadi 試玩調整） |
| Aim Spread Movement Add Degrees | 1.5° | 滿實際移動速度的額外半角 |
| Aim Spread Turn Add Degrees | 1° | 滿車身轉速的額外半角 |
| Aim Spread Turret Turn Add Degrees | 1° | 滿砲塔左右轉速的額外半角；相對車身計算，含有限左右擺動、不含炮管俯仰 |
| Aim Spread Fire Add Degrees | 0.3° | 每次成功開火後立即增加的半角；本發先取樣，影響後續射擊 |
| Aim Spread Fire Recovery Degrees Per Second | 0.2°/秒 | 只回復開火增加的部分；單次 0.3° 約 1.5 秒收回，越小回得越慢，0 表示不自動回復 |
| Aim Spread Cap Degrees | 2.5° | 所有擴散的總上限，包含移動、車身／砲塔轉向與開火後增加量 |
| Aim Spread Grow Degrees Per Second | 4°/秒 | 失準時擴大的速度 |
| Aim Spread Stationary Recovery Degrees Per Second | 1.2°/秒 | 靜止時收縮的速度 |
| Aim Spread Moving Recovery Degrees Per Second | 0.6°/秒 | 滿移動速度時收縮的速度 |

「半角」是炮管中心線到圓錐邊緣的角度，不是整個圓錐張角。移動與轉向按實際速度連續貢獻，停車不是瞬間滿準度；放慢時的回復速度介於兩個設定之間。這些是初版手感起點，不代表最終車型平衡。

砲塔左右轉動也按實際轉速連續增加擴散，停轉後沿用同一回復規則。以目前四型初值而言，車身不動而砲塔滿速旋轉時，目標半角為 1°＋1°＝2°；同時移動／轉車身仍受 2.5° 總上限限制。半透明圓錐會自動呈現這份共同的當前擴散值。

成功開火後再額外增加 0.3°，可逐發累加但仍受 2.5° 上限限制；冷卻中被拒絕的開火不增加。這是開火後的短暫失準，已射出的本發仍使用開火前的擴散角度，不改變既有後座動作。開火額外增加量現在以獨立的 0.2°/秒回復，沒有額外等待計時器：靜止時 1°→開火 1.3°→0.75 秒後 1.15°→1.5 秒後 1°。

移動、車身轉向、砲塔轉向與開火的幅度皆可分別配置。這一版只先獨立開火回復；移動與左右轉向仍沿用原本依車速混合的靜止／移動回復參數，尚未各自拆出回復速度，避免本次手感試調順便改動其他行為。

每次開火只取樣一次方向，砲彈從實際砲口直線飛出。砲塔、炮焰、硝煙與後座仍沿實際炮管方向。現有紅白線表示瞄準中心，**還不是每發彈道或擴散 HUD**；動態圖樣留到下一階段。

試玩追加淡青色半透明圓錐：從實際砲口沿白色瞄準線展開，寬度即時讀取當前擴散半角，長度到白線的碰撞終點或顯示上限。這是可穿透遮擋顯示的輔助體積，不是額外碰撞、每發必然落點或地形上的落點投影；不改砲彈射程。所有場景預設關閉，訓練場可射擊淡藍色開關靶啟用，重開遊戲恢復關閉。開發時仍可在 `main.tscn` → `PlayerRuntime` → `AimPresentation` →「暫時擴散預覽」調整 `Show Spread Cone`，或以 `Spread Cone Color` 的 A 調整不透明度。

## 靶場責任

`training_range.tscn`／`training_range.gd` 管主靶、清除靶、標線與彈著；`training_ground_playtest.gd` 把通用命中事件接進靶場。靶板沒有 HealthComponent／DamageReceiver，既有坦克靶與擊毀換車不受影響。

## 驗證

`tests/tank_aim_spread_smoke.gd` 驗公式、漸變、四型配置與固定 seed 的圓錐方向；`tests/training_range_smoke.gd` 驗幾何、碰撞與彈著清除；既有訓練場與戰鬥邊界測試驗完整接線。兩個新測試已列入 `scripts/quality.mjs`，視覺與手感仍需 leadi 人工驗收。
