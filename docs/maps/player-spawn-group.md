# 玩家出生群組

在 `src/main.tscn` 選取 `PlayerSpawnGroup`，使用移動工具調整出生位置。
群組下的 `Tank` 與 `CameraRig` 是同層節點：編輯時一起平移，遊戲中由既有鏡頭控制器跟隨坦克，不繼承車身轉向。
本次支援平移；請維持群組旋轉為零、縮放為 `(1, 1, 1)`。不要只移動 Tank 來設定出生點，否則會改變初始鏡頭相對偏移。

- 主地圖群組位置：`(-108, 0, -114)`。
- 坦克區域位置：`(0, 0, 8)`；主地圖世界出生位置：`(-108, 0, -106)`。
- CameraRig 區域位置：`(0, 0, 0)`；初始跟隨偏移：`(0, 0, -8)`。
- 訓練場沿用共用 runtime 的原點群組，不變更既有出生點。
- 換車與重生會將世界出生姿態轉成群組區域姿態，新坦克仍放在群組內。

自動回歸：`tests/player_spawn_group_smoke.gd`，涵蓋群組平移、跟隨、車身旋轉、換車、死亡殘骸保留、重生與訓練場綁定。
手動驗收：開啟主場景後按 F6，確認玩家在左上庭院且鏡頭跟隨；停止遊戲後平移 PlayerSpawnGroup，再執行確認出生點與鏡頭一起移動。
