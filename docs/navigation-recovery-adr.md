# ADR：單一原生導航與有限次受阻恢復

## 狀態
已採用；使用者核可實作，自動驗收與獨立複審通過，等待本分支人類試玩。

## 背景與鎖定前提
目標使用者是 leadi 與訓練場敵方 AI；此次用途是親測遊戲行為，不建立通用姿態尋路框架。
類似系統為原生導航路徑跟隨搭配有限恢復狀態；定位是現有遊戲的一次收斂調整。
動機是降低維護複雜度，讓車寬允許的窄口由主要導航路線直接涵蓋。
使用者已在朝前半徑預覽中確認窄口有色塊且坦克會嘗試走入。
範圍只涉及正常導航／受阻恢復與既有車體命令出口；索敵、40/55m交戰距離及最後目擊位置語意不變。

## 決策
- 四車共用朝前通行半徑3.6427174m（最大側向範圍2.6427174m＋原有每側1m）。
- 所有路線只由 NavigationAgent3D 取得；移除獨立直通與兩段中繼搜尋。
- TankController 原有碰撞形狀、轉向 guard、move_and_slide 與慣性煞車不變。
- 無進展3秒觸發恢復：位移達0.5m或朝向進展3度算有進展；正常煞車／待命不累計前進受阻。
- 每個目標嘗試最多2次恢復：停穩至0.1m/s以下，直線低速倒車（上限1.5m/s），最多2m或2秒，預留煞車距離，停穩後重新查原生路徑。
- 恢復中只沿同一命令出口送負 movement，不直接修改 transform／velocity，不額外尋找脫困路線。
- 耗盡次數後 stuck，車身movement/turn皆0。目標位置累計改變3m、新目標世代、重新可見或生命週期重置才有新嘗試。
- clear、停用、死亡、換車、換目標沿用既有取消出口；正常近距交戰不倒車。

## 被否決的替代方案
- 保留直通與兩段捷徑：車寬導航已解決當前路線選擇，維護收益不足。
- 一直倒車重試：使用者選擇有限次重試，避免永久抖動。
- 完整姿態搜尋、多車避讓、封路記憶：不是當前MVP目的。

## 影響
舊捷徑專用測試移除，改驗原生窄口路線與有限恢復；既有一般導航、實體碰撞、索敵和射擊回歸保留。
朝前半徑不是所有姿態皆可通行的保證，長車在狹窄彎角可能耗盡恢復次數而停車。
編輯器與CLI仍共用來源群組與NavigationMesh設定；CLI只額外驗證朝前尺寸下限。

## 詞彙
- 朝前通行半徑：全部碰撞頂點在車身／砲塔朝前姿態的最大橫向偏移＋安全餘裕。
- 有限次受阻恢復：煞停、短倒車、停穩、重查原生路徑，次數有上限。

## 有限驗收矩陣
1. 原生烘焙入口、CLI與朝前四車尺寸一致，來源只含地板及建築。
2. 原生窄口路線、一般四車建築繞行、部分末端／原始目標抵達與純需求介面。
3. 正常旋轉進展不觸發；前進／旋轉受阻觸發；每次先煞停再倒車並重新查路。
4. 後方碰撞不穿牆；兩次失敗終止；同目標維持停止，目標改變可重試。
5. 恢復命令負值可傳遞；stuck不被朝敵轉向覆寫；停用與目標／載具生命週期取消舊倒車。
6. 索敵、最後位置、作戰距離、射擊、控制器碰撞與玩家操控回歸。

信任模型是單一本機Godot及既有場景；不增加並行烘焙、當機恢復、惡意資料或新平台相容承諾。
